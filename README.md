# AI 课件工坊（PPT 生成器）

一句话生成一套能直接讲的课件：**联网找资料 → 自动拆分章节 → 选风格配色 → 带动画放映 → 一键导出 .pptx**。

纯静态网页，不需要服务器、不需要数据库：打开网页，填一次自己的大模型 API Key，就能用。

线上地址：<https://cet4listening.github.io/ppt-ai/>

---

## 功能

| 环节 | 说明 |
| --- | --- |
| 1. 需求 | 对话框里说清楚"年级 + 学科 + 课题 + 时长"，可以上传资料一起参考 |
| 上传 | 支持 txt / md / csv / json / html / pdf / docx / pptx / 图片 / 视频 / 音频；文档自动抽取文字，图片和视频自动生成缩略图可插入幻灯片 |
| 联网检索 | 打开「联网检索」后，先用公共 CORS 代理去 Bing / DuckDuckGo / 中文维基抓资料，再把摘要喂给模型；全部失败会自动降级为模型自有知识，并在对话里标注 |
| 2. 内容结构 | 模型把内容拆成 9–14 页（封面 / 章节页 / 要点 / 两栏 / 图文 / 引言 / 数据 / 清单 / 结束页），可直接改标题、改要点、调顺序、增删页；讲稿提示（notes）自动生成 |
| 3. 风格配色 | 5 种版式风格 × 8 套配色 × 5 种字体 × 6 种动画，右侧实时预览 |
| 4. 成品 | 页面缩略图、点击放大、全屏放映（← → 翻页、N 看讲稿、ESC 退出）、导出可编辑 PPTX、导出像素级还原的图片版 PPTX、打印成 PDF |

## 使用

1. 打开网页 → 右上角「设置」
2. 填 **API Key**（默认接口是 `https://api.deepseek.com/v1`，模型 `deepseek-chat`；任何 OpenAI 兼容接口都能用，换成别的 Base URL + 模型名即可）
3. 回到对话框输入需求，例如：`帮我生成一个小学三年级英语第一节课内容的 PPT`
4. 依次走完 4 步，点「导出 PPTX」

> API Key 只保存在你本机浏览器的 localStorage 里，页面不会把它发到除你填的那个模型接口以外的任何地方。

## 本地运行

```powershell
# 任意静态服务器都行（需要支持 Range 才有进度条拖动）
node tools\serve.js 8800
# 然后打开 http://127.0.0.1:8800/ppt-ai/
```

## 部署

已通过 GitHub Pages 部署在组织的 `ppt-ai` 仓库：

```powershell
cd ppt-ai
git add -A
git commit -m "更新"
git push          # 国内网络不通时加：git -c http.proxy=http://127.0.0.1:7890 push
```

1–2 分钟后自动生效。

## 已知限制

- **联网检索**依赖公共 CORS 代理（allorigins / corsproxy / Jina），国内网络有时不通；不通时会自动降级并在对话里提示。想稳定可以自己部署一个 Cloudflare Worker，把地址填进「设置 → 搜索代理」。
- **图片**：文本模型看不懂图片内容，所以图片/视频只作为幻灯片素材使用，不会被"理解"。
- **PPTX 动画**：PowerPoint 文件格式里的动画需要专门的 OOXML 支持，导出的 .pptx 是**静态排版**；动画只在网页放映模式里出现。
- 一次生成大约消耗几千 token，长课件（14 页 + 讲稿）会更多。
- 浏览器端解析大文件（>50MB 视频）只记录元信息，避免卡死。

## 🔒 安全与防护

- 纯静态站，资料不上传服务器；Key 默认以混淆形式存在本机，可在设置里改成「仅本会话」。
- 已启用 CSP、错误信息打码、请求频率限制、图片地址白名单、上传文件本地解析、开发页不上线。
- 想让 Key 完全不进浏览器？`security/worker-cf.js` 提供了一个 3 分钟可部署的 Cloudflare Worker 代理（藏 Key + 限流 + Origin 白名单）。详见 [security/README.md](security/README.md)。

## 导出逐条版 PPTX（会“一条条出现”的 pptx）

第 5 步工具栏点 **「导出逐条版」**：把每一页按「已经显示了几块」拆成多张静态页——
第 1 张只有标题，第 2 张多一条，依此类推。播放时按页翻，效果就是逐条出现，
**不依赖 PowerPoint 动画 XML，任何播放器（PowerPoint / WPS / Keynote / 投影仪 / 微信预览）都一致**。

- 代价：页数变多（一条要点约多一页），文件稍大（约 200KB 起）
- 讲稿备注只挂在每组第一张；「课后思考」挂在每组最后一张
- 原始「导出 PPTX」仍然保留：单页、可编辑、无动画
